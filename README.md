
# Attendance Tracker

A simple and user-friendly web application to track and manage student attendance.

## Live Demo
https://attendancetracker-0500.netlify.app/

## About the Project
Attendance Tracker is a web-based application developed as part of my BCA Summer Project. It helps students maintain attendance records and monitor their attendance percentage.

## Features
- Subject-wise attendance tracking
- Mark students as Present or Absent
- Calculate attendance percentage
- Set minimum attendance targets
- Monthly attendance records
- Easy-to-use interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website.
2. Add your subjects.
3. Set your attendance target.
4. Mark attendance as Present or Absent.
5. Monitor your attendance percentage.
